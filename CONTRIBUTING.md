# Contributing to MENU

Thank you for helping improve MENU!

## Before you start

- Search the repository to avoid duplicate examples.
- Choose a clear category and descriptive folder name.
- Keep each example independent and easy to run.
- Do not copy another creator's code or design without permission and attribution.

## Folder naming

Use this format:

`CATEGORY/###-short-example-name/`

Example: `03-mega-menus/021-ecommerce-category-menu/`

## Required files

For a plain HTML/CSS/JS example:

- `index.html`
- `style.css`
- `script.js` (if needed)
- `preview.png`
- `README.md`

For framework projects, include the package/setup files they need.

## Pull request checklist

- [ ] I checked that this example is not a duplicate.
- [ ] I tested desktop, tablet and mobile layouts.
- [ ] I tested keyboard interaction and visible focus.
- [ ] I checked reduced-motion behavior where animation is used.
- [ ] I included a screenshot and README.
- [ ] I checked the browser console for errors.
- [ ] I credited external assets and checked their licenses.

## Example README template

```md
# Example Name

Short description of this navigation pattern.

## Preview
![Preview](preview.png)

## Technology
HTML, CSS, Vanilla JavaScript

## Features
- Responsive layout
- Keyboard-friendly interaction
- Customizable colors and spacing

## Run locally
Open `index.html` in a browser or use VS Code Live Server.

## Customization
Explain the main classes, variables and behavior.
```

## Pull request title

Use a clear title, such as:

- `feat: add responsive mega menu`
- `fix: improve mobile sidebar keyboard behavior`
- `docs: add setup instructions`
