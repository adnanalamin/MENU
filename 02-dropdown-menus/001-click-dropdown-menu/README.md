# Accessible Click Dropdown

**Category:** Dropdown Menus  
**Technology:** HTML5, CSS3, Vanilla JavaScript  
**Dependencies:** None

## Run
Open `index.html` or use VS Code Live Server.

## Customize
Edit the trigger and submenu links in `index.html`; style the panel in `style.css`.

## Accessibility
Uses a native button, `aria-expanded`, `aria-controls`, Escape-to-close, outside-click dismissal, visible focus, and reduced-motion support.

## Preview
Capture desktop and mobile screenshots and save the preferred image as `preview.png`.
