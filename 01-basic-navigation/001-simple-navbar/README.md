# Simple Responsive Navbar

**Category:** Basic Navigation  
**Technology:** HTML5, CSS3, Vanilla JavaScript  
**Dependencies:** None

## Run
Open `index.html` or use VS Code Live Server.

## Customize
Change logo/links in `index.html`; colors and spacing in `style.css`.

## Accessibility
Uses `aria-expanded`, `aria-controls`, Escape-to-close, visible focus, and reduced-motion support.

## Preview
Capture desktop and mobile screenshots and save the preferred image as `preview.png`.

## Test
- [ ] Desktop/tablet/mobile
- [ ] Mobile toggle works
- [ ] Escape closes
- [ ] Focus is visible
- [ ] No overflow or console errors
